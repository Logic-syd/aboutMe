# Geographic map extracts

These six GeoJSON files contain real geographic features from OpenStreetMap, not invented street layouts. The original five extracts include roads, water, waterways and selected green spaces; Berlin contains a central-city street network. They are loaded from this site's origin and rendered using an original Leaflet style; no public tile servers, Google Maps, external runtime API, tracking script or API key is used.

The original five extracts retain public OSM way/relation identifiers. Each file records its source, retrieval time and actual bounding box.

Generated manually with `python3 scripts/export-place-maps.py` using the official read-only OSM bounding-box API. The export narrows dense extracts to respect the API's 50,000-node limit, filters out buildings and unrelated objects, rounds coordinates to six decimals and simplifies geometry. The site renders the actual source extent. These are curated area maps, not complete, live navigation maps. The dashed reference circle marks a city area or nearby landmark, not a verified office location.

Berlin uses the published OSM geometry in [EqualStreetNames Berlin](https://github.com/EqualStreetNames/equalstreetnames-berlin/blob/master/data/ways.geojson), under the same ODbL map-data licence. Regenerate it with `python3 scripts/export-berlin-map.py /path/to/ways.geojson`; the script documents the download URL. It clips streets to the central-city extent, drops unrelated metadata, removes duplicate segments and groups geometry by street name. The extract is a static street map, without live venue data or comprehensive park and water layers.
